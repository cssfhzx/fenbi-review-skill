# 错因分析的写法

解析文字的质量，决定了复盘文档有没有用。写得好的分析能让你下次遇到同类题直接避开；写得差的只是把「你错了」换个说法。

## 三个层次

### 差：复述答案

> Q5 应该选 C。A 不对，B 也不对，C 最合适。

这种分析没有任何信息量。看完还是不知道 A 错在哪。

### 中：说明理由

> Q5 选 C。「高高在上」不能修饰法律，应该用「遥不可及」；第二空「红线」对应「警戒」而不是「教育」。

有信息了，但还停留在这一道题。

### 好：给出可迁移的判断规则

> Q5 选 C。锚点在「一辈子不打交道」——这是距离远的表述，对应「遥不可及」。
> 「高高在上」形容人脱离实际、脱离群众，主语必须是人或拟人化主体，修饰「法律」是对象错位。
> 「红线」是禁止性边界，对应「警戒」；「教育」是正向引导，方向相反。
> 记法：遇到「某人/某物 + 形容词」的搭配，先问「这个词能修饰什么」。

好的分析有**三个要素**：

1. **锚点**：题干里哪个词决定了答案（可指认、可复现）
2. **错项机理**：错误选项具体错在哪个字/哪个限制
3. **可迁移规则**：下次遇到同类题的判断动作

## 锚点怎么找

锚点是题干里**已经给出的信号**，不是你的联想。常见类型：

| 锚点类型 | 例子 | 对应答案方向 |
|---|---|---|
| 分号/对举 | 「学以致用，是知识的实用化；学以致思，是知识的___化」 | 找「实用」的反义 → 抽象 |
| 顿号并列 | 「流于表面、___」 | 与「流于表面」同义 → 浅尝辄止 |
| 转折词 | 「但」「其实」「而」「然而」 | 转折后才是重点 |
| 定义句 | 「无法发展到更高级的阶段」 | 定义即答案 → 落后 |
| 后文评价句 | 「彰显……回应挑战的主体性与生命力」 | 回读找呼应 → 淬炼 |
| 惯用搭配 | 「从___迈向现实」 | 蓝图 → 现实（固定对举） |
| 动词/对象 | 「制服」 | 要求「难以驯服」义 → 桀骜不驯 |
| 语法结构 | 「___中描绘的古代社会面貌」 | 必须填文字载体 → 只言片语 |
| 数据口径 | 「2016～2022」 | 间隔 6 年，不是 7 年 |

**找锚的动作要前置**：读完题干先扫一遍这些信号，再去看选项。顺序反了就会「先看词再找理由」，把「说得通」当成「最贴」。

## 错项怎么拆

不要写「A 不恰当」，要写清楚**哪里不恰当**。四种拆法：

**1. 拆语素**

> 支持 vs 支撑：「持」是扶住（扶助推进，施动者是人）；「撑」是顶住（托底使立，施动者是物）。

**2. 拆对象**

> 淹没 → 只配液体（洪水淹没村庄）；掩埋 → 配固体（泥沙掩埋足迹）。

**3. 拆程度**

> 摧毁 → 一步到位；侵蚀 → 渐进侵害。题干有「长此以往」，只能选渐进的。

**4. 拆方向**

> 融汇 → 融进其中（文化融汇到生活）；汇聚 → 聚到一起（人流汇聚）。题干主语是文化，方向只能是从外向内融。

## 搭配库怎么写

`colloc` 字段不是词典释义，是**条件反射清单**。格式统一为：

```
词　→　对象/限制/场景
```

好的：

```
经久不息　→　只配掌声、欢呼（不配方式、风尚）
消纳　→　富余电力、新能源发电（电力术语）
严苛　→　条件、环境、标准（中性）；苛刻　→　人的要求（含贬义）
```

不好的：

```
经久不息　→　形容持续很长时间
消纳　→　消化吸纳
```

后者把释义抄了一遍，下次还是不知道能不能用。

**判断标准**：这条 colloc 能不能让你在考场 3 秒内做出判断？不能就是没写好。

## 错因归类的粒度

粗了没用，细了记不住。合适的粒度是**能对应一个改法**：

| 太粗 | 合适 | 太细 |
|---|---|---|
| 理解错误 | ② 不明白选项的功能 | 「没注意到高高在上只能修饰人」 |
| 粗心 | ① 时间范围/口径错误 | 「2016～2022 数成了 7 年」 |
| 基础不牢 | ③ 适用对象/搭配错误 | 「不知道经久不息只配掌声」 |

中间那列对应 `references/cause-taxonomy.md` 里的编号。

## 训练计划怎么写

训练计划不是口号，是**明天就能执行的动作**。对比：

| 差 | 好 |
|---|---|
| 加强成语积累 | 每天过一遍「词+对象」清单 9 条，见词先问「主语是谁」 |
| 提高阅读速度 | 每天限时 5 道片段阅读（6 分钟），先圈转折词再选 |
| 多做练习 | 两周后重做本卷，目标 55% 以上 |

好计划有三个特征：**有数量、有时间、有验收标准**。

按投入产出比排序，最便宜的放第一条。

## 做对但值得记录的题

`note` 字段只给真正有价值的正确题写，比如：

- 这题是靠某个技巧快速做对的，值得固化
- 这题容易错，你做对了说明某个动作到位了
- 这题的选项有陷阱，你避开了

不要给每道正确题都写。写多了会把重点冲淡。
